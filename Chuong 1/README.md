# Chương 1 — EduHub

Project C# console mô hình hóa hệ thống quản lý câu lạc bộ sinh viên.

## Cấu trúc

- `Domain/`: các lớp `Club`, `Member`, `Event`, `Registration`, `CheckIn`.
- `docs/`: user stories, sơ đồ lớp và tài liệu liên quan.
- `Program.cs`: điểm khởi chạy chương trình.
- `EduHub.Ch01.csproj`: project .NET 10.

## Chạy chương trình

```bash
dotnet run --project EduHub.Ch01.csproj
```
